## Running it

```bash
npm install
npm run dev      # localhost:3300
```

Next.js 16, React 19, TypeScript, Tailwind CSS v4. Static export, deployed by GitHub Actions.
Every figure on the page is the same figure as the long portfolio, compressed — nothing here
is rounded or restated.
